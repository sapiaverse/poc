# Sapiaverse (EXP-001)

A browser viewer for the saved logs of a 21-day simulated society of 50 synthetic residents.
Playback reads saved JSON files only; it makes no model calls and does not rerun the simulation.

- Residents, lives, friendships, locations and the Chicago environment are synthetic study assumptions, not real people.
- No original human survey records, model requests or credentials are included.
- Trip lines interpolate between recorded endpoints; they are not exact street routes.

Map data © OpenStreetMap contributors, ODbL.
